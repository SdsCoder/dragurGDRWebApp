# Dragur

Scheda interattiva di Nefastor, installabile sul telefono come app.

## Pubblicarla con GitHub Pages

1. Su GitHub crea un repository nuovo chiamato `dragur`, pubblico, vuoto.
2. Nel repository premi **Add file → Upload files** e trascina tutti i file di questa cartella (non la cartella stessa). Premi **Commit changes**.
3. Vai in **Settings → Pages**. In "Build and deployment" scegli **Deploy from a branch**, branch **main**, cartella **/ (root)**, poi **Save**.
4. Dopo uno o due minuti la scheda è online all'indirizzo `https://TUONOME.github.io/dragur/`.

## Installarla su Android

Apri l'indirizzo con Chrome, menu ⋮ → **Installa app** (o "Aggiungi a schermata Home").

## Portare i dati

Nella scheda dentro Claude: Registro → Backup della scheda → Esporta, e il testo viene copiato.
Nell'app: Registro → Backup della scheda → incolla il testo → Importa (due tocchi).
Fai ogni tanto un backup: i dati vivono solo nel telefono.

## Aggiornare

Sostituisci `index.html` nel repository con la versione nuova. L'app si aggiorna da sola alla prima apertura con internet; i dati restano.
